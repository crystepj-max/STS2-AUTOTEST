## 三个独立失败源（详见分诊 task.yaml triage 节）

- **F1 持久 — 状态工具漂移**：`scripts/setup-mac-runner.sh` 描述
  `~/actions-runner-autotest` + `com.sts2.autotest-runner.plist` + `run.sh`，
  本机均不存在（`ls` 与 `launchctl list` 实测）。按旧脚本操作打不到真实服务，
  直接解释 Issue 症状 3「旧状态命令报告 Stopped、停止/启动未替换后台进程」。
  另发现 `svc.sh status` 必须从 runner 根目录运行，否则报
  `Failed: Must run from runner root or install is corrupt` —— 状态工具易用性另一缺陷。
- **F2 间歇 — 长轮询中断自愈**：BrokerServer 长轮询反复被 cancel
  （`TaskCanceledException` ← `SocketException (89)`），每轮 4 次退避重试后恢复，
  单日多轮（详见 runner-diag 证据）；AAD token 获取偶发 2–15s。
- **F3 间歇 — 代理 TLS 抖动**：issue-13 已实证本机直连 GitHub 超时不可用，
  必须走 ClashX 代理（`evidence/network-probe-20260813.md`）；间歇抖动可自愈。
